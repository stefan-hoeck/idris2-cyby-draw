# idris2-cyby-draw

A drawing tool for molecules running in the browser and written in Idris2.

## Example App

To try out the example app, you need [pack](https://github.com/stefan-hoeck/idris2-pack)
to build it as well as [curl](https://curl.se/) to download some third-party
CSS files. Just run the build script and open `draw.html` in your browser of choice:

```sh
./makeapp.sh
firefox draw.html
```
